# Retired

Do not create or publish a Confluence release note.

NWM, SPI, and WOE release notes are the **Release Notes** section on the Jira fix version. Use [create-jira-release](../create-jira-release/SKILL.md). The description on that fix version is one sentence. The release note markdown goes in `--release-notes-file`.
