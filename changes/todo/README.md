# Todo

Work that is not done yet. Each note says what is wrong and what done looks like. End the note with `## Done when`. A note that waits on another links to that note.

When a task is finished, move its note into `changes/done/` and append a section to `changes/ai-revision-log.md` if a Cursor rule changed or a repository in this workspace now runs differently. The section names the local user and the UTC time. It does not record a commit. It says what changed, concretely enough to unpick.

The log records local changes made in this workspace. It does not record changes other people make in the repositories.
